# 单局复盘：20260707_184956_ironclad_a0

结果：Ironclad A0，击败 Guardian 后推进到 Act2 Collector，F33 死亡，未胜利。该局为 `clean_trainable/completed_clean`，终局由 MCP null 后 synthetic recovery 写出，validation 为 `usable_with_recoveries`。

受启发式/搜索影响的行为：买 Cleave、删 Strike、拿并升级 Second Wind、低血休息、Snake Plant 前使用 Fear Potion 和 Skill Potion、Collector T2 连用防御/生命药水，主要都是现有规则和搜索驱动。Guardian 开局使用力量/速度类药水也属于启发式，不是模型直接接管。

学习/模型影响：route-risk assist 只通过 `model risk -12.0` 改变路线分数，不直接控制 MCP。card reward 产生了 Sword Boomerang、Second Wind、Limit Break、Shrug It Off、Battle Trance、Seeing Red、Armaments 等训练样本。combat value NN 仍为 shadow，`runtime_authority=false`。

训练价值：该局是最丰富的 Act2 样本。正向样本包括 Second Wind/Shrug/Cleave 在 Byrd、Snake Plant、Shelled Parasite 场景中的局部价值；负向样本包括 Philosopher's Stone 增强多敌压力、Battle Trance 在无后续能量时收益不足、Collector T5 incoming 52 时无法防御。

后续影响：下一轮应让模型学习“多敌 Boss 大招窗口前的资源储备”和“召唤物击杀优先级”。该局不能算 A0 胜利，也不能把外部 prior 记为 live 控制来源。

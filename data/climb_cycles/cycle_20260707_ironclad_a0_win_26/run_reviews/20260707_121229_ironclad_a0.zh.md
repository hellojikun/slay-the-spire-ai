## 结论

- Guardian 战里多次防住或部分防住大攻击，但没有形成稳定 Mode Shift/击杀节奏。

- 本局没有模型直接接管 live 行为。
- 唯一被排除的 combat-search label 来自 Guardian T7；replay audit 显示当前策略匹配实际动作，不匹配被排除 label。因此它应继续作为审计样本，而不是训练标签。
- Shrug It Off、Thunderclap、Second Wind、Ghostly Armor、Spot Weakness 等奖励选择会进入本地 card model 和 learned memory 的训练证据。
